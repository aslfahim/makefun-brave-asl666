A tiny Node program that writes one short, steadying text — a candle in the window of a house that has stood two hundred winters, outlasting the wind at the glass — to /output/entry.txt for make.fun's relaxation-judge bounty. The images live in a small ordered map, are joined in reading order, length-checked, and written deterministically.

## Run it

```sh
node main.ts
```
